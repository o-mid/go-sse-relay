go-sse-relay

Push an event in. Stream it out live. Connect a channel, publish a sample event, and watch it arrive over Server-Sent Events.

Checking… bus — instance — stream auth —

Try it in 3 steps

Stay on the same channel for connect and publish, or you will not see the event.

  1. 1
    Pick a channel Any short name works (letters, numbers, _ / -). Default is fine.
  2. 2
    Connect the stream Opens a live SSE subscription. Status turns green when ready.
  3. 3
    Publish a sample event Sends payment.updated to that channel. It should appear in the log instantly.

Tip: use one channel name for both buttons (for example demo_user).
